=== FOLDER MUSIK / BACKSOUND ===

Letakkan file musik di sini dengan nama berikut:

  music_menu.mp3    → Musik di layar Menu & How To Play (loop)
  music_battle.mp3  → Musik saat Battle berlangsung (loop)  
  music_result.mp3  → Musik di layar Result/Kemenangan (opsional)

Format yang didukung: .mp3, .ogg, .wav

Tips:
- Gunakan .ogg untuk ukuran file lebih kecil
- Volume default 60% (bisa diubah di constants.py → MUSIC_VOLUME)
- Jika file tidak ada, game tetap jalan tanpa musik

=== FOLDER SFX ===
Letakkan sound effect di folder ../sfx/ :

  sfx_correct.wav   → Suara jawaban benar
  sfx_wrong.wav     → Suara jawaban salah  
  sfx_hit.wav       → Suara karakter kena serangan
  sfx_click.wav     → Suara klik tombol (opsional)
